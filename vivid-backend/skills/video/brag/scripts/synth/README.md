# synth

Vendored unchanged from [Mort1d/motion-graphics-skills](https://github.com/Mort1d/motion-graphics-skills)
(`skills/motion-graphics/assets/template/audio/synth`, commit in `UPSTREAM`), MIT licence in `LICENSE`.
`references/genre-cards.md` comes from the same repository.

A dependency-free, deterministic synthesizer in Node: 80 calibrated voices (drums, bass, pads, keys, leads,
UI sounds, foley, builders), buses with sidechain ducking, automation, reverb/delay sends, and a loudness-normalised
render (ITU BS.1770). `node selftest.mjs` renders every voice and checks it.
