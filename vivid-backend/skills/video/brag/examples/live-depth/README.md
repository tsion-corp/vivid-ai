# Worked example: depth, micro-interactions, live data (9 s)

A tested HyperFrames render of the `depth-and-interaction.md` recipes:
- an immersive camera fly-in with parallax layers;
- a bet button going press → "Placing…" with a spinner → "Cash out";
- a crash multiplier and its trajectory curve driven by one progress value;
- a 60 s countdown ring depleting and turning red;
- a build log and a UI build synced from one step table;
- a glass "You won!" modal over a darkened, depth-blurred world, leaving with anticipation.

It's a technique sheet, not a full brag. It has no score, and no scene tags.
